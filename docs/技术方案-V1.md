# 网页版 MRender 技术方案 V1.0

> 目标：在浏览器（HTML 端）实现一个 KeyShot 工作流级别的实时渲染系统，调用本地 GPU（macOS 走 WebGPU/Metal 后端），支持拖入模型、上材质、贴标签、选 HDRI 环境、打灯光、全参数可调、最终渲染出图。Beta 版可封装成桌面软件（底层仍是 HTML 架构）。
>
> 日期：2026-08-11　｜　状态：待评审　｜　项目目录：`~/Desktop/workbuddy文档/MRender-Web/`

---

## 1. 项目定位

| 项 | 说明 |
|---|---|

## 2. 技术架构

```
┌──────────────────────────────────────────────────────┐
│ 表现层  React 18 + Zustand（设计稿 S00 直接落地）      │
│   三栏布局: 左资源库 / 中央视口 / 右项目面板(六页签)     │
│   六页签: 场景 | 材质 | 环境 | 照明 | 相机 | 图像       │
│   材质库 / 摄影棚库 / 渲染窗口                         │
├──────────────────────────────────────────────────────┤
│ 应用层  场景管理 / 命令系统 / 项目文件                  │
│   Scene Graph（物件/部件/材质引用）                    │
│   撤销重做（命令栈）                                  │
│   项目序列化 JSON（保存/打开）                        │
├──────────────────────────────────────────────────────┤
│ 渲染引擎层  双引擎共用同一份场景/材质/灯光数据           │
│   实时预览  → Three.js 光栅化（PBR 材质, 丝滑交互）     │
│   高质量出图 → three-gpu-pathtracer（WebGPU 路径追踪） │
├──────────────────────────────────────────────────────┤
│ 资源层                                               │
│   模型导入: OBJ / GLTF / GLB / FBX                    │
│   环境: RGBELoader + Poly Haven 免费 HDRI              │
│   纹理: TextureLoader + 标签贴图（PNG 透明底）          │
└──────────────────────────────────────────────────────┘
```

**双引擎原理**：Three.js 场景（Object3D / Mesh / Material）同时被光栅化渲染器和路径追踪渲染器消费。实时预览时跑光栅化（毫秒级反馈）；点「渲染」时把同一场景交给路径追踪器，用 WebGPU 在本地 GPU 上做光线追踪（支持玻璃折射、焦散、HDRI 反射、景深），渲染完成后导出 PNG。

## 7. 风险清单与对策

| # | 风险 | 等级 | 对策 |
|---|---|---|---|
| 1 | **three-gpu-pathtracer 与本机 WebGPU 兼容性** | 高 | **D1 第一天验证**；失败则降级：光栅化 + 高质量后处理（ToneMapping/抗锯齿/景深）出图，流程不断 |
| 2 | 路径追踪库与 Three.js 版本冲突 | 中 | 锁定已验证版本组合（文档记录版本号） |
| 3 | 标签精准贴合瓶身 | 中 | Beta 用参数化定位（offset/rotation/scale），后续做拖拽式 |
| 4 | 大模型（高面数 OBJ）性能 | 中 | 导入时做顶点压缩/自动简化选项；渲染时路径追踪按采样逐步收敛 |
| 5 | 玻璃/液体折射焦散物理正确性 | 中 | three-gpu-pathtracer 支持 transmission/IOR；复杂焦散后续优化 |
| 6 | 降噪质量 | 低 | three-gpu-pathtracer 自带降噪；不足则后期 OIDN-wasm 方案 |

## 9. UI 落地方式

设计稿 `S00-主窗口框架.html`（含 12 个设计 token / 组件规格）直接落地为 React 组件：

- `components/Layout/` → 三栏框架、菜单栏、工具栏、状态栏
- `components/Library/` → 资源库七子库页签、材质球网格、搜索、分类下拉
- `components/ProjectPanel/` → 右侧六页签：场景树/材质属性/环境/照明/相机/图像
- `components/Viewport/` → 视口、Gizmo、坐标轴、渲染统计浮窗
- `components/RenderWindow/` → 渲染进度/设置/结果窗口

设计规范 `MRender-UI-设计规范-V1.md` 为样式基准（CSS 变量 → 设计 token 一一对应）。
